# Alerte de sécurité

::: info Info
**La SuperKey possède des privilèges plus élevés que l'accès root.**
:::

::: info Info
Utilisez des clés fortes et protégez-les contre toute divulgation afin de préserver la sécurité de votre appareil. À partir des nouvelles versions, APatch vérifie la **signature du gestionnaire** au lieu d'imposer l'authentification par SuperKey dans le gestionnaire ; installez uniquement l'APK officiel d'APatch Manager.
:::

::: warning Attention
Des clés faibles ou compromises (ou des gestionnaires tiers re-signés) peuvent entraîner une prise de contrôle non autorisée de votre appareil.
:::

::: danger Danger
**NE FLASHEZ AUCUN NOYAU PATCHÉ PAR DES TIERS.**
:::
