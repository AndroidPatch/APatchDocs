# Security alert

::: info
**The SuperKey has higher privileges than root access.**
:::

::: info
Use strong keys and protect them from exposure to maintain device security. Starting from newer versions, APatch verifies the **manager signature** instead of enforcing SuperKey authentication in the manager; only install the official APatch Manager APK.
:::

::: warning
Weak or compromised keys (or untrusted re-signed managers) can lead to unauthorized control of your device.
:::

::: danger
**DO NOT FLASH ANY KERNEL PATCHED BY THIRD-PARTIES.**
:::
