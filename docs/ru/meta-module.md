# Метамодули

Метамодули — это революционная функция в KernelSU, которая переносит ключевые возможности модульной системы из ядра в подключаемые модули. Такой архитектурный сдвиг сохраняет стабильность и безопасность KernelSU, открывая больший потенциал для инноваций в экосистеме модулей.

Впоследствии APatch также внедрил этот механизм метамодулей, вынеся встроенную логику монтирования разделов из основного демона (`apd`) в отдельные метамодули с сохранением совместимости с метамодулями для экосистемы KernelSU. Поэтому в новых версиях APatch для работы обычных модулей APM, изменяющих файлы `/system` и других разделов, **необходимо сначала выбрать и установить один из метамодулей** (например, реализацию OverlayFS, Magic Mount или Hybrid Mount из таблицы ниже; одновременно может быть активен только один метамодуль), иначе монтирование файлов модулей не будет работать.

::: warning Внимание
После установки метамодуля необходимо перезагрузить устройство перед установкой остальных модулей.
:::
