# Предупреждение

::: info
**Суперключ имеет более высокие привилегии, чем root-доступ.**
:::

::: info
Используйте надежные ключи и защищайте их от утечки, чтобы обеспечить безопасность устройства. Начиная с новых версий, APatch проверяет **подпись менеджера** вместо обязательной аутентификации по SuperKey в менеджере — устанавливайте только официальный APK APatch Manager.
:::

::: warning
Слабые или скомпрометированные ключи (а также переподписанные сторонние менеджеры) могут привести к несанкционированному управлению устройством.
:::

::: danger
**НЕ ПРОШИВАЙТЕ ЯДРА, ПРОПАТЧЕННЫЕ СТОРОННИМИ ЛЮДЬМИ.**
:::
